# H2 Reflection – M6

1. I compared the deterministic, retrieval, and LLM assistant paths using 25 evaluation cases.
2. The deterministic path achieved 9/25 correct answers, while retrieval and LLM (stub) each achieved 18/25.
3. The deterministic path correctly handled all 7 abstention cases, while retrieval and LLM (stub) handled 6/7.
4. The LLM stub had a higher maximum latency than retrieval (13.6 ms versus 0.3 ms) without improving correctness.
5. This comparison showed that retrieval improves document-based answering, but source relevance and reliable abstention still need improvement.
