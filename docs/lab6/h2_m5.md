# H2 — Individual reflection (M5 / fumeneko)

RAG is similar to an open-book exam: the assistant retrieves relevant knowledge-base passages before generating an answer, rather than relying only on its pretrained knowledge.
The retriever ranks document chunks, so the quality of the question and the relevance of the retrieved evidence both affect whether the answer can cite the expected source.
For M5, I added five evaluation cases covering distinct thesis-registration, library-renewal and student-card facts, plus out-of-scope and privacy questions that should be refused or answered with abstention.
The revised 25-case stub evaluation achieved 17/25 correct for retrieval and the LLM path, with 6/7 abstention cases correct; E22 and E23 still missed their expected source IDs.
This work showed me that passing unit tests is not enough to establish retrieval quality: evaluation cases also need diverse wording, verified source IDs and clear reporting of unresolved failures.
