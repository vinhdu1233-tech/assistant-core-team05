# H2 — Individual reflection (M1 / vinhdu1233-tech)

Think of RAG as an open-book exam: the assistant looks up a relevant page before answering instead of relying only on memory.  
Retrieval selects the relevant handbook sections, and the language model turns those sections into an answer.  
In A1, our Python code checks that the search actually found a source and that its score meets the configured threshold.  
For example, if the documents provide no information about an exam rule, a fluent answer alone is not evidence.  
When retrieval is insufficient, the assistant should admit uncertainty and direct the student to the Training Office rather than invent a rule.
